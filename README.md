# Zimo Zhuang Personal Website

Files:
- `index.html` — website
- `profile.jpg` — profile photo
- `Zimo_Zhuang_Resume.pdf` — resume

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `zimozhuang.github.io` or `personal-website`.
2. Upload all three files in this folder to the repository root.
3. If the repository is named `zimozhuang.github.io`, the site will be available at:
   `https://zimozhuang.github.io/`
4. Otherwise, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes deploying, copy the public website URL into your DS3 application.

Before submitting, open the public URL in an incognito/private window to verify that it works without signing in.
